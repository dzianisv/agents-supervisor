# Agents Supervisor Knowledgebase

Concise project reference for agents working in this repository.

## Files

- `architecture.md` - runtime architecture, core modules, state, and data flow.
- `command-surface.md` - user commands, tools, scripts, CI, training, and install surfaces.
- `supervisor-concepts.md` - current supervisor modes, categories, heuristics, and configuration concepts.

## Scope

This knowledgebase is factual and codebase-derived. It is not product documentation and should be updated when runtime behavior, command names, state paths, or training/eval flows change.
