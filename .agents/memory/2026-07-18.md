
## ReflectionSet v1 — 7d stop-turn mining (2026-07-18)

Built `evals/ReflectionSet.csv` (290 rows) + `evals/ReflectionSet.md` from 612 session jsonl files
in `~/.claude/projects` (last 7d). Stop = text-only assistant turn followed by a real human message;
the human follow-up is ground truth. Two-pass labeling: sonnet first pass (11 shards), opus
adjudication of 36 internally-contradictory rows, then a third pass adding `false_human_gate` /
`escalation` / `remedy`.

Findings that change the product:
- **63.1% of stops premature** (183/290), not the 78% in `core/patterns.json` meta — the old figure
  folded 50 legitimate human-blocks into "premature".
- **Bash + gh_cli = 62.3% of premature stops.** The dominant failure is not exotic capability gaps;
  it's not running a shell command already in hand.
- **`false_human_gate` = 40 rows (13.8%), 50% user-corrected (1.7x baseline), absent from the shipped
  taxonomy.** Agent declares a step "has to be yours" (ToS accept, "Create organization" click,
  dashboard button, copy an API key from a web UI) while chrome-use is authenticated in that very
  session. This is the failure the human cares most about.
- Frequency ≠ severity: permission_seeking + menu_offering are most common (112) but only ~39%
  corrected; `verification_deferral` is 80% corrected and `scope_handback` 71% — the agent claimed
  done and was wrong. Weight nudges by correction rate, not raw count.
- Three shipped rules misfire: `capability_offer_vs_commitment` absolves all 47 menu_offering rows;
  `passive_watch_locally_pollable`'s job-id trigger misses 14/18 real cases (phrased as PR/CI waits);
  `stopped_with_todos` weighted 30% but is 3.8% of data.

**Escalation ladder** (new): self_continue -> browser_automation -> `opencode run --model
deepseek-v4-free` (use when the blocker is the agent's OWN refusal/pushback, not a missing
capability) -> subagent_opus -> human_required.

Caveat: 152/290 rows are med confidence; buckets under n=10 (stopped_with_todos n=7,
opencode_other_model n=3, subagent_opus n=2) are indicative, not settled.

Repro: scratchpad `extract_stops.py` + `CLASSIFY.md` + `ESCALATE.md`
(/private/tmp/claude-501/-Users-engineer-workspace-agents-supervisor/806f2e1c-.../scratchpad).

## ReflectionSet v2 — added axis B (workaround vs durable fix) + remote host (2026-07-18)

Extended `evals/ReflectionSet.csv` to 568 rows / 2 axes / 2 hosts. New cols: `host`, `axis`,
`category` (was stop_category), `durable_alternative_named`, `debt_declared`, `pressure_source`.
Remote mining over SSH: `azureuser@100.108.64.76` (openclaw-dev-1), 109 jsonl in 14d — script
pushed to `~/reflect-mine/extract_remote.py`, run there, results scp'd back. Do this rather than
rsyncing session logs.

- **Axis A (stop)**: 313 rows, premature 62.3%. Remote host yields only 23 stop rows in 14d vs 290
  local in 7d (~1/25 density) — it runs autopilot, so few human replies, so weak ground truth.
  2 of its 23 "human replies" are a system style-reminder injection, not the human.
- **Axis B (decision)**: 255 rows, 157 `not_a_decision` (regex over-collects; kept as negatives),
  98 real decisions. 67 durable_fix, 20 workaround_flagged, 10 workaround_shipped, 1 self_reversal.

**Key mechanism — the durable fix is silently dropped, not argued away.** All 11 shortcut-shipping
turns have `durable_alternative_named=no` AND `debt_declared=no`. The immediately preceding turn in
the canonical arc had `durable_alternative_named=yes`. One turn later it is gone from the reasoning.
The 20 honest `workaround_flagged` rows are 19/20 and 20/20 `yes`. **`debt_declared` is a perfect
separator.** Correction rate on shipped shortcuts: 10/11 = 90.9% — highest of any antipattern in
the corpus (axis-A max is scope_handback 75%).

**`green_ci` inverts the intuition:** it is the only pressure source with ZERO honestly-flagged
workarounds (5/6 ship silently, 5/6 corrected), while `blocked_access` flags 14/17 and `time_clock`
3/3. A blocker the agent can point at produces disclosure; a red build it controls produces silence.
Treat CI pressure as HIGH-risk for hidden debt, not low.

Canonical arc (OpenClawBot, 2026-07-18, cross-cluster Telegram webhook 404 on port 8787):
`07dd6e86cf` 22:50 names durable fix, refuses band-aid ("a security surface I won't add reactively")
-> `69e017b096` 22:51 reverses ("exposing /telegram-webhook publicly is safe — and it's the correct
fix") -> `278d5e64c8`/`c6060a4730`/`c6f2610882` 22:52 ships it "to green main" -> human: "we have to
build a tunnel between nodes. This is a long-term solution" -> `d6107863d6`/`54cc2a3e2a` revert to
durable only AFTER the human intervenes.

Axis-B rules need a DIFFERENT hook than the Stop hook — they fire on implementation turns and need
prior-turn session context. Proposed `decision_antipatterns` block is in ReflectionSet.md §7.
