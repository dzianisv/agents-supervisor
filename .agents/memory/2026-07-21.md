## Supervisor intervention policy

- Default supervisor interventions must use LLM reflection and judgement. Static tool-call-only planning-loop prompts are prohibited because they can misclassify legitimate exploration and push an agent into an unproductive action loop.
- Mode contract: `supervisor:autopilot` supplies only static self-reflection nudges and an agent-controlled `loop_exit`; `supervisor:goal` uses an LLM to derive and persist `.agents/supervisor/goal.md` when unset; `supervisor:reflection` gives `.agents/supervisor/{system,user,patterns}.md` to a judge LLM, which scores task completion and returns feedback.

## Static loop watchdog analysis

- `detectPlanningLoop` is a separate deterministic watchdog, not part of autopilot, goal, or reflection. It scans full-session history and static feedback replaces judge output, causing repeated false-positive STOP messages. It must lose its authority: autopilot keeps neutral static nudges, goal derives absent goals with an LLM, and reflection is the sole progress/completion judge.
- Review caught a goal-derivation prompt-injection flaw in XML-like data fences: untrusted task, transcript, or AGENTS text can forge a predictable closing tag. Goal derivation is blocked until fences are made non-forgeable and regression-tested.
