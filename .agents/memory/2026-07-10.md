
## Runtime divergence CC vs OpenCode (issue #45)
- CC judge reads only `.supervisor/rubric.md` (+ `~/.config/agents-supervisor/rubric.md`); OpenCode additionally reads `.agents/supervisor/{SystemPrompt,Patterns,User}.md` and uses a different global path (`~/.config/opencode/supervisor/rubric.md`). `.agents/supervisor/User.md` is a silent no-op on CC — bit a user in the field.
- Decision: one shared core in `core/`, thin runtime wrappers; CC gains `.agents/supervisor/*` support; parity test = identical judge prompts from identical config. Tracked in #45; blocked on the #19+#23 consolidation PR.
- Judge back-delegation ("User must decide" in next_steps) tracked in #44 — next_steps must be agent-actionable; only needs_user_action may reference the user.
